# Карта ШІ-патернів

Вставте текст і побачте, які місця схожі на «ШІ-стиль». Сторінка підсвічує фрагменти, а при наведенні курсора показує, що з ними не так, як виправити і чи це нормально для вашого жанру.

**Онлайн:** https://mykyta-soloid.github.io/ai-pattern-map/

## Як користуватися

1. Оберіть жанр: науковий, журналістика й блог, маркетинг або загальний. Від жанру залежить серйозність знахідок.
2. Вставте текст у поле.
3. Натисніть «Проаналізувати» (або Ctrl/⌘ + Enter).
4. Наведіть курсор на підсвічене місце. На телефоні торкніться його. Клік закріплює підказку, `Esc` закриває.
5. Праворуч є фільтри за рівнем серйозності, список усіх знахідок і загальні спостереження.

Кнопка «Приклад» підставляє демонстраційний текст.

## Два режими

**Швидкий.** Працює в браузері за готовими правилами, текст нікуди не надсилається. Ловить конкретні формулювання: метакоментарі, порожні зачини, роздуту значущість, безіменні «дослідники», конструкції «не лише…, а й», слабкі дієслова, ШІ-лексику, пафосні кінцівки. Показує й «живі сигнали», які радше властиві людському письму: різні апострофи, дрібні збої милозвучності.

**Глибокий (Claude).** Надсилає текст у Claude і розуміє зміст: бачить твердження без джерел, загальні зачини, які підійшли б до будь-якої теми, однотипний ритм. Потрібен ваш ключ Anthropic API. Текст і ключ надсилаються з браузера напряму в Anthropic API, сервера в цього проєкту немає. Ключ зберігається лише в цьому браузері й тільки якщо ви поставите галочку.

Швидкий режим не розуміє змісту. Наприклад, загальний зачин без характерних слів він не побачить. Для цього є глибокий режим.

## Рівні знахідок

- **Сильний:** найімовірніша проблема для вашого жанру. У науковому тексті це твердження без імен і посилань.
- **Середній:** помітний патерн, який варто перевірити.
- **Слабкий:** дрібниця або ознака жанру.
- **Живий сигнал:** місце, яке радше схоже на людське письмо. Доказом авторства не є.

## Важливо

Патерни є ознаками, а не доказом, що текст писав ШІ. Детектори лише вгадують, тому інструмент показує конкретні місця, які можна перевірити самому. Рішення про авторство залишається за людиною.

Правила налаштовані на українську, частково на російську. Для інших мов швидкий режим майже нічого не знайде.

## Запуск локально

Збірки немає: відкрийте `index.html` у браузері. Для тестів потрібен Node.js:

```bash
node test/engine.test.js
```

## Структура

- `index.html` — інтерфейс.
- `engine.js` — рушій правил, працює в браузері й у Node.
- `sample.js` — демонстраційний текст.
- `test/engine.test.js` — тести рушія.

## Як додати своє правило

У `engine.js` у масиві `RULES` додайте об'єкт з полями `id`, `cat` (назва патерну), `sev` (базова серйозність), `res` (регулярні вирази), `what`, `fix` та `gn` (поради за жанрами). Серйозність для конкретного жанру можна змінити в `GENRES[жанр].ov`.
