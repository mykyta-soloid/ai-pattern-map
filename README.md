# Карта ШІ-патернів

Одна HTML-сторінка, яка підсвічує в тексті місця, схожі на «ШІ-стиль». Наведіть курсор на підсвічений фрагмент і побачите, що з ним не так, як це виправити та чи це нормально для жанру.

Приклад у репозиторії: два абзаци філософського тексту про мову, перевірені скілом [no-ai-slop](https://skills.sh/petergyang/no-ai-slop/no-ai-slop).

## Як відкрити

Збірки немає. Відкрийте `index.html` у браузері. Шрифти підтягуються з Google Fonts, без інтернету сторінка працює зі стандартними.

## Що вміє

- Чотири рівні: сильні, середні, слабкі патерни та «живі сигнали» (місця, які радше схожі на людське письмо).
- Рівень видно за формою лінії, а не лише за кольором.
- Підказка на наведення, фокус із клавіатури або дотик. Клік закріплює підказку, `Esc` закриває.
- Фільтри за рівнями й список усіх знахідок, клік по знахідці прокручує до фрагмента.
- Світла й темна теми, мобільна розкладка.

## Як підставити свій текст

1. У `index.html` замініть текст усередині `<article class="paper">`.
2. Обгорніть потрібні фрагменти в `<mark data-id="f1">…</mark>`. Фрагменти не мають перетинатися.
3. У масиві `F` у кінці файлу додайте запис з тим самим id:

```js
f1: {
  cat: "Без джерела",   // назва патерну
  sev: "strong",        // strong | medium | weak | human
  what: "Що не так",
  fix: "Як виправити",
  genre: "Що це означає для вашого жанру"
}
```

## Важливо

Патерни є ознаками, а не доказом, що текст писав ШІ. Детектори лише вгадують, тому інструмент показує конкретні місця, які можна перевірити самому. Для наукових текстів іменникову мову й терміни варто вважати нормою жанру, а найсерйозніше рахувати твердження без джерел.

Розмітка в прикладі зроблена вручну за результатами скіла. Автоматичного аналізу в цій сторінці немає.
